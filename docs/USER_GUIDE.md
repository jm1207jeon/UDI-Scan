## 소개

UDI-Scan은 Zebra DS9908-SR 바코드 스캐너를 위한 전문 애플리케이션입니다. 바코드 스캔과 동시에 이미지를 자동으로 캡처하여 저장할 수 있으며, 스캔된 데이터는 Excel, Word, Notepad 등 모든 응용 프로그램에 자동으로 입력됩니다.

### 주요 기능
- ✅ 바코드 자동 스캔 및 키보드 입력 시뮬레이션
- ✅ 바코드 이미지 자동 캡처 및 저장
- ✅ 실시간 스캔 이력 표시
- ✅ 이미지 프리뷰 기능
- ✅ 설정 자동 저장 (재시작 후에도 유지)
- ✅ 고속 연속 스캔 지원

## 시작하기

### 1단계: 프로그램 실행

바탕화면 또는 시작 메뉴에서 **UDI-Scan** 아이콘을 클릭하여 프로그램을 실행합니다.

### 2단계: 스캐너 연결 확인

프로그램이 실행되면 상단에 스캐너 연결 상태가 표시됩니다:

- **🟢 Connected: DS9908-SR00004ZZWW** - 정상 연결
- **⚪ Scanner Disconnected** - 연결 안 됨 (스캐너 확인 필요)

### 3단계: 첫 번째 스캔

1. Excel, Word, Notepad 등 데이터를 입력할 프로그램을 엽니다
2. 커서를 입력하고 싶은 위치에 둡니다
3. DS9908 스캐너로 바코드를 스캔합니다
4. 스캔된 데이터가 자동으로 입력됩니다!

## 기본 사용법

### 바코드 스캔하기

1. **입력 위치 선택**
   - Excel 셀, Word 문서, 웹 브라우저 입력창 등 원하는 위치에 커서를 둡니다

2. **바코드 스캔**
   - DS9908 스캐너의 트리거를 당겨 바코드를 스캔합니다
   - 또는 Presentation Mode에서는 바코드를 스캐너 앞에 가져다 대면 자동 스캔됩니다

3. **자동 입력**
   - 스캔된 바코드가 즉시 입력 위치에 입력됩니다
   - 자동으로 Enter 키가 눌러집니다 (Excel에서 다음 행으로 이동)

### 스캔 이력 확인

왼쪽 패널의 **Scan History**에서 최근 스캔 기록을 확인할 수 있습니다:

```
12:34:56
8806085124567
EAN-13

12:34:45
1234567890128
UPC-A
```

- 시간: 스캔 시각 (HH:mm:ss)
- 바코드 값
- 바코드 타입 (EAN-13, UPC-A, QR Code 등)

### 이미지 캡처

#### 이미지 캡처 활성화/비활성화

1. **Image Capture** 버튼을 클릭하여 토글합니다
   - 🟢 **Enabled** (초록색): 모든 스캔 시 이미지 자동 저장
   - 🔴 **Disabled** (빨간색): 이미지 저장하지 않음

2. 기본 설정은 **Enabled** 상태입니다

#### 캡처된 이미지 확인

- 오른쪽 패널의 **Last Captured Image**에서 최근 캡처된 이미지를 확인할 수 있습니다
- 이미지는 실제 스캔 시점의 바코드 사진입니다

### 저장 경로 변경

1. **Save Path** 옆의 **Browse...** 버튼을 클릭합니다
2. 이미지를 저장할 폴더를 선택합니다
3. 선택한 경로는 자동으로 저장되며, 다음 실행 시에도 유지됩니다

**기본 저장 경로**: `C:\Users\[사용자이름]\Documents\UDIScan\Images`

### 저장되는 파일 형식

이미지는 다음 형식으로 저장됩니다:

**파일명**: `바코드값_yyyyMMdd_HHmmss_fff.jpg`

예시:
- `8806085124567_20250130_123456_789.jpg`
- `1234567890128_20250130_123500_123.jpg`

## 고급 기능

### 연속 고속 스캔

UDI-Scan은 초당 수십 개의 바코드를 빠르게 연속으로 스캔해도 데이터 손실 없이 처리합니다.

**사용 시나리오**:
- Excel에서 재고 목록 입력 시
- 대량의 제품 바코드를 빠르게 스캔해야 할 때

**팁**:
- Excel에서 첫 번째 셀 선택 후 연속으로 스캔하면 자동으로 아래로 입력됩니다
- 이미지 캡처를 비활성화하면 더 빠른 처리가 가능합니다

### 스캔 이력 관리

- **Clear History** 버튼: 스캔 이력 전체 삭제
- 이력은 최대 100개까지 자동으로 유지됩니다
- 프로그램을 종료하면 이력은 초기화됩니다

### 상태 표시

하단 상태 바에서 다음 정보를 확인할 수 있습니다:

```
Ready | Total Scans: 45 | Images Saved: 45
```

- **Ready**: 스캐너 준비 상태
- **Total Scans**: 현재 세션에서 스캔한 총 개수
- **Images Saved**: 저장된 이미지 개수

## 문제 해결

### 스캐너가 연결되지 않아요

**증상**: "Scanner Disconnected" 또는 "No scanner found" 메시지

**해결 방법**:
1. USB 케이블이 PC에 제대로 연결되어 있는지 확인
2. 장치 관리자에서 DS9908이 인식되는지 확인
3. CoreScanner Driver가 설치되어 있는지 확인
4. 프로그램을 종료하고 다시 실행
5. PC를 재시작

### 바코드가 스캔은 되는데 입력이 안 돼요

**증상**: 스캔음은 나지만 Excel/Word 등에 입력되지 않음

**해결 방법**:
1. 입력하려는 프로그램에 포커스가 있는지 확인 (클릭해서 활성화)
2. 입력 위치에 커서가 있는지 확인
3. **관리자 권한으로 실행된 프로그램**에는 입력이 불가능합니다
   - 예: 관리자 권한으로 실행된 Excel
   - 해결: Excel을 일반 권한으로 다시 실행

### 이미지가 저장되지 않아요

**증상**: "Image Capture: Enabled"인데 이미지 파일이 생성되지 않음

**해결 방법**:
1. **Image Capture** 버튼이 Enabled (초록색)인지 확인
2. 저장 경로의 폴더가 존재하는지 확인
3. 해당 폴더에 쓰기 권한이 있는지 확인
4. 디스크 용량이 충분한지 확인 (이미지 1개당 약 100KB~2MB)
5. 저장 경로를 다른 위치로 변경해보기

### 스캔 속도가 느려요

**증상**: 바코드를 스캔해도 입력이 지연됨

**해결 방법**:
1. **이미지 캡처를 비활성화**하면 더 빠릅니다
2. PC 성능이 낮은 경우 백그라운드 프로그램을 종료
3. 저장 경로를 SSD 드라이브로 변경 (HDD는 느림)
4. 대량 스캔 후 잠시 대기하여 처리 완료 확인

### 특수 문자가 제대로 입력되지 않아요

**증상**: 하이픈(-), 슬래시(/), 괄호 등이 잘못 입력됨

**해결 방법**:
- Windows 키보드 레이아웃을 **영어(미국)**로 변경
- 한글 키보드에서는 일부 특수 문자가 다르게 입력될 수 있음

## FAQ

### Q1. 여러 개의 DS9908을 동시에 사용할 수 있나요?

**A**: 현재 버전은 1대의 스캐너만 지원합니다. 향후 업데이트에서 다중 스캐너 지원 예정입니다.

### Q2. 다른 Zebra 스캐너(DS4308, DS8108 등)도 사용할 수 있나요?

**A**: CoreScanner를 지원하는 대부분의 Zebra 스캐너에서 작동합니다. 단, 이미지 캡처 기능은 이미징 스캐너만 지원합니다.

### Q3. 이미지 캡처가 안 되는 스캐너가 있나요?

**A**: DS9908-SR은 이미지 캡처를 지원하지만, 일부 1D 레이저 스캐너(예: LS2208)는 이미지 캡처 기능이 없습니다.

### Q4. 스캔 이력을 파일로 저장할 수 있나요?

**A**: 현재 버전에서는 지원하지 않습니다. 향후 업데이트에서 CSV 내보내기 기능을 추가할 예정입니다.

### Q5. 이미지 포맷을 PNG나 BMP로 변경할 수 있나요?

**A**: 현재는 JPEG만 지원합니다. 향후 업데이트에서 설정 옵션을 추가할 예정입니다.

### Q6. 바코드 스캔 시 Enter 키를 입력하지 않도록 할 수 있나요?

**A**: 설정 파일(`%APPDATA%\UDIScan\settings.json`)에서 `AutoSendEnter`를 `false`로 변경하면 됩니다.

### Q7. 네트워크 드라이브에 이미지를 저장할 수 있나요?

**A**: 네, 가능합니다. Browse 버튼으로 네트워크 경로를 선택하거나, 직접 UNC 경로(`\\서버\폴더`)를 입력하면 됩니다.

### Q8. 프로그램이 시작 프로그램에 등록되나요?

**A**: 아니요. 필요 시 Windows 시작 프로그램 폴더에 바로가기를 추가하시면 됩니다.

### Q9. 라이선스가 필요한가요?

**A**: UDI-Scan은 MIT 라이선스로 무료입니다. Zebra CoreScanner Driver는 Zebra에서 무료로 제공합니다.

### Q10. 업데이트는 어떻게 확인하나요?

**A**: 현재는 수동 업데이트만 지원합니다. 공식 GitHub 저장소에서 최신 버전을 확인하세요.
